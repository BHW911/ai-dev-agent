# AI Dev Agent - 自动化代码生成与任务编排工具

一个基于大模型的开发辅助 Agent，用于自动生成代码模板、优化重复逻辑，并提供简单的任务编排能力，提升日常开发效率。

---

## 🚀 项目背景

在日常开发过程中，大量时间会消耗在重复性工作上，例如：

- 编写接口模板（CRUD）
- 补全基础函数逻辑
- 重构已有代码结构
- 添加注释与规范化命名

这些工作技术含量不高，但耗时且容易出错。

本项目的目标是：  
👉 将这些“低价值重复劳动”自动化

---

## ✨ 核心功能

### 1. 自动代码生成
根据输入描述或上下文代码，自动生成：

- API 接口模板（Express / Flask 风格）
- 工具函数
- 基础业务逻辑代码

---

### 2. 代码优化 / 重构

支持：

- 变量命名规范化
- 拆分过长函数
- 自动补充注释
- 简单逻辑优化

---
